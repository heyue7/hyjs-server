# Feedback85 增量候选与验收边界

本批在已通过的碎片箱/Boss 线路分离之后继续处理用户追加。源码完成与上线分别记录；本文件写入时新增 Go 规则尚未完成最终编译/MySQL和原机验收。首次到75级点角色觉醒的进程崩溃尚未复现并修复，不能用觉醒副本入口补全代替该故障。

## 训练

`gradient-v3` 保留原费用、上限、等级和确认/取消。对每属性比例 `r=current/cap`，正向概率为 `round(9500-7000*r²)/10000`，三档相同。幅度基点为普通60、金币90、钻石140；正向按剩余距离，负向按当前值的20%，再在80%至120%的整数区间取样。1/5/10次逐步更新实际比例。低剩余值取整可能使不同档位同为1。取消不退款，待确认值不加入战力。

新库种子采用新具名来源；已有配置启动不覆盖。显式 `--apply-feedback85` 在维护期校验管理员和有效服务时钟，原子更新三条标准训练规则与觉醒目录，拒绝混合版本或配置漂移；已发布后只接受完整同源幂等状态。

客户端必须同时使用对应 `HYJS.DungeonContent.dll` 与夜林资源目录兼容；NavMesh重排、旧持久缓存、全部五章原机和已开箱/击败怪后续局需实际验收。原复活/受伤再挑战限制仍保留，不能把配置中的3次复活称为已完整实现。
