## 功能完成后的 UI 整理

- 后台前端功能新增、修改或修复完成后，**必须读取并使用 [ui-polish](/Users/lirui/.codex/skills/ui-polish/SKILL.md) 整理本次受影响的前端 UI，再完成交付验收**。主代理与执行代理均须执行。
- 检查相关列表、详情和编辑流程的文案、视觉层级、布局、留白、控件与交互反馈；删除重复标题、无用说明和空壳，保留真实业务、有效集成及有助操作的信息。沿用现有后台配色和组件规范，不擅自扩大改版范围。
- 通过浏览器实际检查桌面和窄屏，操作受影响的保存、取消、返回、错误及加载状态；视觉调整保留必要的同视口、同状态前后对照。静态检查和构建通过不能代替实际 UI 验收，未验范围如实记录。
