# 天赋材料资格与激活前复核

以正式69的原机程序集和已审查姓名字体候选为输入。原GetAdvenceAvailableHeroList只过滤低培养、上阵、助阵及显式锁定，遗漏真实远征占用等服务端保护，导致材料1/1仍激活失败。

服务端沿原instance-lock/state读取同一角色事务下的材料不可用集合与原因；远征/主角/上阵/助阵/锁定/派遣/培养的保护与最终消耗共用规则。此投影不改资源或远征占用。旧客户端仍被保护并收到具体原因。

新辅助程序集只接管共享天赋候选GUID过滤和TalentDetail.OnActiveBtn两处。页面先读取当前材料状态；每次激活通过一次独立最新读取复核后才回到原激活方法，同一挂起操作只续接一次。页面关闭、换角色/天赋、会话变化及读取失败均停止续接。消耗、扣费、前置、原回包和重试仍由原协议服务负责。

界面沿用原数量、按钮和toast，不引入新样式。发布输入保留正式69所有Java及547战斗引擎方法，新增helper和两个方法的允许清单逐字核对；原材料保护helper保持。
