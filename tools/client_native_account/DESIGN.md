# 刀剑神域账号控件视觉规范

保留原游戏登录背景、账号窗口、输入框与登录流程，仅调整按钮和记住密码控件。设计参考为用户提供的原机登录截图及游戏内原有半透明灰白窗口。旧候选的公会金色按钮已弃用。

## 尺寸、颜色与交互

以下像素以 1280×576 参考画面为基准，实际运行沿用原 NGUI 缩放与安全区域。

| 内容 | 规范 |
| --- | --- |
| 原窗口 | 约386×280，位置与原面板一致，保留原关闭按钮 |
| 参考标题栏 | 高42，标题20号，干净的中文无衬线字体 |
| 原输入行 | 约292×34，保留账号、钥匙图标与密码掩码 |
| 主按钮 | 约124×36，青蓝渐变 #48BED5 → #2598B9，白字 |
| 次按钮 | 同尺寸，浅灰白 #F4F7F8 → #DDE9ED，深蓝灰字 #314855 |
| 按钮排布 | 同一基线，间距约18，4像素切角、约1像素细边，18号居中文字 |
| 记住密码 | 约16×16方框、勾选时青蓝底白勾；与14号文字间距7，整行均可点击 |
| 文案 | 登录、注册账号；注册态为注册、返回登录；确认密码：请再次输入 |
| 状态 | 普通、按下、禁用；注册进行中防止重复提交；注册成功返回手动登录 |

不得使用厚金属边、金色纹章、铆钉、大面积霓虹、立体黑色描边字。记住密码没有“开/关”按钮或装饰底座。按钮中文字由原游戏字体实时渲染，图片仅提供无字底图。

## 发送给 image 的完整设计要求（中文对应稿）

以参考图1的现有账号窗口为修改目标，以参考图2的游戏内半透明灰白窗口为风格参考。保留浮空城、天空、原页面构图、窗口位置和大小、页面外围所有元素。只优化账号窗口内部控件，采用刀剑神域简洁、轻盈的悬浮系统菜单风格。

颜色统一为冷灰白、蓝灰文字和克制的青蓝强调。参考面板使用 #F4F7F8、90%不透明度，辅助灰 #D8E0E4，细边 #A3B5C0，文字 #314855，强调 #39BDD7。保持386×280的原窗口占位。标题栏42像素，标题“游戏登录”20号，右上角关闭图标18像素、触摸区域40像素。输入行保持292×34，账号演示文字使用 Player001，密码使用圆点，禁止显示真实账号或密码。

密码框下方左对齐放16×16的标准复选框，细蓝灰边，选中为青蓝底白色勾，右侧7像素间距放14号“记住密码”。整行可以点击，行内不添加其他功能，不出现“开/关”文字，不做成第三个大按钮。

底部居中放两个124×36的按钮，间距18像素，统一基线。左侧“注册账号”使用浅灰白面、蓝灰字；右侧“登录”使用青蓝渐变、白字。四角轻微4像素切角、约1像素细边，仅保留细小角部亮线。文字18号、无黑色描边、准确居中。保留轻微阴影，不出现厚金属边、金色、纹章、铆钉、重倒角或大范围发光。

输出应呈现真实游戏截图的观感，无说明标注、无设备边框、无水印。原机实施继续使用原窗口；参考图中的面板装饰不作为整页替换素材。
