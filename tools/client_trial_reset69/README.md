# 原试炼重置入口

以固定正式68 APK为输入，在UI.RushPage.Refresh末尾追加一个只负责显示的回调。原挑战、重置、确认弹窗、文字、精灵、大小及点击处理保持；可用次数大于零且原挑战按钮可见时，将两个原按钮在底部并列。失败与次数耗尽时恢复原坐标。服务器继续负责进度、费用、次数、待结算战斗放弃及新轮次切换。无进度重置仍返回原错误且不扣次数。

构建入口build.py要求固定输入SHA与全新输出目录，核所有方法元数据/ABI、唯一修改UI.RushPage.Refresh及547个原引擎方法不变。输出由tools/client_release/package_native.py签名并校验。运行期附加类只保存页面原按钮坐标，随Unity页面清理。
