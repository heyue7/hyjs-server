# Wanted recorded controls qualification

The caller drives the unchanged original APK engine through per-round automatic controls. It captures the original terminal protobuf. Player commands can be supplied to the server calculator; NPC AI, legality, random values, damage, HP, clocks and the full terminal protobuf must be calculated independently and match exactly.

`native-proof.json` pins the original assembly, caller/host source and two public records. `service/testdata/p12_wanted_live_controls86.json` contains the public normal/deadly regression records. Their typed input is the existing P12 native fixture at indices 0 and 2. No production snapshots are included.

A separately authorized single production fight was temporarily compared against the original engine; its automatic terminal matched exactly. The rejected user End request was not retained by the service, so the diagnosis does not claim to have replayed that exact request. Later-round controls were independently generated using the frozen input.

Settlement rejection metadata releases the cross-mode presentation lock after a definitive rejection, while retaining the immutable paid fight for retry. Network/database failures retain the lock. This changes no rewards, attempt costs or existing receipt proofs.
